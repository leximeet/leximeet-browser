# 词遇浏览器插件隐私政策

更新日期：2026年10月5日 · 适用版本：1.0.0

本政策由词遇（LexiMeet）项目维护者提供，适用于词遇浏览器插件。词遇用于在网页阅读中查词、采集单词和语境，并安排词汇学习。你可以独立使用，也可以主动确认连接本机词遇桌面应用。

## 1. 插件处理哪些数据

| 数据                                             | 使用目的                                                                 |
| ------------------------------------------------ | ------------------------------------------------------------------------ |
| 当前网页地址、标题和页面会话信息                 | 显示阅读入口、定位当前页面、维持侧栏会话；这些临时信息不构成完整浏览历史 |
| 用户启动遇见分析后读取的已加载正文               | 匹配目标词和已有词条，显示高亮与词卡；分析本身不自动生成遇见记录         |
| 用户采集的单词、原句、摘录、来源地址、标题和时间 | 保存单词的真实阅读语境，供以后查看和学习                                 |
| 用户填写的笔记、单词本及关联                     | 整理个人词汇资料                                                         |
| 学习目标、练习回答、结果、用时和学习记录         | 展示进度、更新单词熟悉度、安排后续学习与复习                             |
| 展示、发音、采集偏好，以及本机连接状态和配对信息 | 保存设置并维持用户确认的桌面连接                                         |

显示悬浮入口不等于扫描网页正文。只有用户主动启动遇见分析或采词，才读取相应正文或选词语境。读取范围排除输入框、密码框、可编辑区域等；插件不使用浏览器历史或 Cookie 接口读取完整历史、登录凭据或网站会话。

当前版本没有词遇账号登录、云同步、广告或遥测上传。插件不会为广告、用户画像或与词汇学习无关的用途记录用户行为。

## 2. 数据保存在哪里

**独立运行：** 个人词条、语境、笔记、学习记录和主要偏好保存在扩展源的本地 IndexedDB 中，连接与配对信息保存在独立的本机 IndexedDB 中；悬浮入口、教学等少量设置使用扩展本地存储，临时草稿使用扩展会话存储。以上资料均不使用浏览器同步存储（storage.sync）。

**连接桌面：** 插件会通过本机原生通信组件发现词遇桌面端，并显示连接提示；发现不自动接管资料。只有用户在浏览器确认连接后，才读取桌面业务资料，并将新采集写入本机桌面应用。原浏览器独立资料被封存，不自动导入或合并。明确断开连接后，恢复原独立资料；连接失效时暂停相关读写，不将桌面采集改写到独立资料。

桌面应用自身的数据管理和可能提供的其他服务，适用桌面应用的说明与隐私政策。断开连接不会删除已经保存到桌面的资料。

## 3. 哪些情况会访问网络

| 情况                                 | 接收方与发送信息                                                                                               |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 播放单词发音，包括用户启用的练习发音 | 默认向有道的 HTTPS 发音接口发送当前词头和口音参数；若选择自定义服务，则向用户填写的公开 HTTPS 音频地址请求发音 |
| 用户选择下载词典升级                 | 向 GitHub Release 及其资源分发地址请求公开词包；不随请求上传个人词库、语境、笔记或学习记录                     |
| 用户主动联系支持                     | 邮箱服务会处理用户自行发送的邮件地址、正文和附件；我们仅用于回应该请求                                         |

插件不主动将整段网页正文、来源链接、个人笔记或整条遇见记录作为发音业务参数发送。外部服务仍能接触词头和正常网络请求信息，例如 IP 地址，以及浏览器策略允许的来源信息（Referer）；来源信息可能包含网站来源或页面地址。第三方服务对这些请求的处理适用其自身隐私政策。词遇不会把网页语境和学习记录上传给词遇开发者的服务器。

公开词包作为数据校验和解析，不作为远程程序执行。扩展的运行代码随安装包提供。

## 4. 采集保护与权限

默认采集设置会按规则替换部分常见敏感内容为 `xxx`，限制语境长度，并清理来源链接。规则不能识别全部个人信息或商业秘密；用户可调整采集设置，连接模式使用桌面的采集策略。

普通 HTTP/HTTPS 网站访问权限用于显示阅读入口以及用户启动后的查词和采集。当前标签、脚本注入、存储和原生侧栏权限分别用于当前页面操作、挂载入口、本机设置和侧栏展示；本机通信、通知和定时任务权限用于可选桌面连接及发现提示。通知和定时任务不用于系统学习提醒。

你可以通过浏览器的扩展权限设置限制网站访问或关闭通知。隐藏悬浮球只改变显示，不等于撤回网站访问权限。限制权限后，相应网页功能可能无法使用。

本机资料由浏览器资料目录和操作系统的访问控制保护；本政策不承诺额外的数据库加密。

## 5. 有限使用与分享

词遇浏览器插件对用户数据的使用和传输遵守 Chrome Web Store 用户数据政策，包括 Limited Use（有限使用）要求。数据仅用于上述用户可见的词汇阅读、整理和学习功能。

我们不出售用户数据，不将其用于广告定向、信用评估或贷款判断。除用户选择的发音服务、词包下载服务、本机桌面连接和主动支持联系所需处理外，插件不向第三方上传个人词库、笔记、语境或学习记录。

开发者不会后台查看你保存在设备上的私人资料。若你主动提供特定内容以请求支持，我们只处理解决该请求所需的信息；请勿在公开问题反馈中附上凭据或私人数据库。

## 6. 保留、修改与删除

独立个人资料保留在当前浏览器资料目录中，直到用户修改、删除或清除扩展的本地数据。页面会话信息在失效后释放；未提交草稿可能在当前浏览器会话内恢复，保存在扩展会话存储中。插件不设定个人词库的自动到期删除时间。

你可以在管理页修改笔记、单词本和关联，使用回收站管理词条。移入回收站是可恢复的操作，不等于永久删除。若需完整清除独立资料，需清除本扩展的 IndexedDB、本地存储（storage.local）和会话草稿（storage.session），必要时重新加载或重启扩展；需要操作指引时可联系下述邮箱。清除这些数据不会删除桌面应用中的资料，桌面资料需在桌面应用中另行管理；用户自行复制的资料目录或其他备份也需另行删除。

支持邮件仅用于处理用户请求和必要的问题追踪；如果希望删除已提供的支持材料，可联系下述邮箱。浏览器商店自身的安装统计、账号或评价由相应平台处理，适用平台政策。
