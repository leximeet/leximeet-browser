# 隐私、采集与权限

个人资料默认只保存在当前浏览器资料中。连接模式下，新采集直接写入 Desktop，原浏览器资料会封存。1.0.0 没有账号、云同步、遥测上传或个人资料导入导出。

## 采集边界

| 设置                | 默认           | 范围                 |
| ------------------- | -------------- | -------------------- |
| 同语境去重          | 7天            | 0–365天；0关闭       |
| 敏感内容替换为`xxx` | 开启           | 可关闭，影响后续采集 |
| 单句长度上限        | 500 UTF-16单元 | 120–2000             |

先脱敏，再截取第一处选词所在的句子；长句以目标词为中心裁剪。UTF-16 范围必须仍精确命中所选词，不能切开 emoji 代理对。原句、摘录、采集注释和来源标题经过清理后才保存，不额外保存未脱敏副本。选词本身落在敏感值中时，会阻止采集。

内置规则识别邮箱、电话、证件号、通过Luhn校验的卡号、JWT与有明确标签/前缀的常见凭据；**无法可靠识别所有人名和商业秘密**。网页自身的原文不会被词遇改写。关闭脱敏不能恢复已经替换的内容；重新开启不批量重写旧事实，但重复回执按当前策略提供安全投影。

同一词身份和安全语境在滚动七天内只保留一次。比较键使用 NFC、Unicode 空白归一和大小写归一，并保留标点差异；显示的原句和精确选词范围不会改写。来源、笔记或单词本不同，不会使同一句变成新语境；重复采集不新增笔记、关系、积分、修订或成功通知。需要调整已有内容时，请使用管理入口。已撤销的记录和发生时间在未来的记录不参与该窗口查重。

连接时由 Desktop 执行其采集策略，独立偏好不被改写；明确断开后恢复原偏好。重试请求时保留原载荷指纹和身份，超时后先查询原回执，不生成新事件掩盖失败。

## 网络和存储

| 数据/请求                  | 去向                                                                  |
| -------------------------- | --------------------------------------------------------------------- |
| 词条、语境、笔记、学习记录 | 独立IndexedDB，或连接中Desktop                                        |
| 公开词包                   | 固定Dictionary Release，逐文件核验SHA                                 |
| 发音                       | 有道或用户设定的公开HTTPS服务，业务参数为公开词头，仍有正常网络元数据 |
| Native连接                 | 浏览器后台→本机Host→Desktop受信通道                                   |
| 网页内容脚本               | 仅当前公共卡片、词位与有限偏好；不收到完整笔记/历史/凭据              |

网页音频请求未强制清除来源信息，发音服务可能接触浏览器策略允许的 Referer，以及 IP 等网络元数据；“词头参数”不等于整个请求只有词头。

来源链接只接受经过清理的 HTTP(S)，会去掉账号凭据、查询串等敏感参数。Markdown 仅渲染安全文本结构和 HTTP(S) 链接，不执行 raw HTML、脚本，也不自动获取外部图片。

## 七项API权限

| 权限              | 用途                         |
| ----------------- | ---------------------------- |
| `activeTab`       | 用户操作后的当前标签临时访问 |
| `scripting`       | 在已授权网页挂载阅读器       |
| `storage`         | 小型展示偏好与安全元数据     |
| `sidePanel`       | 窗口级原生阅读侧栏           |
| `nativeMessaging` | 可选Desktop本机连接          |
| `notifications`   | 发现/连接通知                |
| `alarms`          | 低频探测已经运行的Desktop    |

HTTP/HTTPS 网站访问权限和一个主 frame 静态脚本用于默认显示悬浮球；**默认挂载入口不等于自动扫描正文**。只有用户主动使用遇见或采集时，才读取正文。没有`tabs`、`downloads`、`file://`、任意文件或对网页公开的业务接口。受限内部页、商店页、PDF等不保证注入。

Chrome 可能提示“读取和更改网站数据”；用户可在扩展的网站设置中限制访问。隐藏悬浮球只改变展示，不等于撤回权限。已获`activeTab`的页面在关闭或跨来源导航前，可能保留临时授权。通知横幅受系统许可和专注模式控制。

安全问题见[SECURITY](../SECURITY.md)，请勿在公开Issue附真实凭据、完整数据库或未清理的网页截图。

面向用户的公开声明见[隐私政策](隐私政策.md)。商店填写表和账号配置在仓外发布资料中保留；公开的构建与分发要求见[发布指南](发布指南.md)。
