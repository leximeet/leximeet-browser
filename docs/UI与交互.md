# UI与交互

界面保留平面的阅读布局、绿色强调、轻分隔线与明暗主题。用明确的按钮和简短反馈传达状态，较长的解释放在帮助或悬浮提示中；不把历史原型视为当前功能。

## 阅读布局

原生侧栏与网页是两个渲染表面。上方操作与管理入口放在同一行；词表和下方词卡分别滚动，词卡约占 40% 高度。遇见列表按大小写归一词头显示一词一行，原网页位置仍保留；选中另一处时，该行和词卡跟随真实位置，采集草稿不按词合并。侧栏开着仍保留悬浮球；进入管理页后关闭阅读侧栏。网页私人历史只在可信扩展界面展示，不注入普通网页覆盖层。

悬浮球拖动超过 6px 后进入拖拽状态，离边缘 64px 后变为 32px 收集篮；蓝框只圈定一个真实 Range（可跨 em/strong）。读取范围仅限指针下的正文块，防抖为 150ms；松手时仍须命中当前词，在空白、编辑区或代码中松手，以及按 Esc，都不会保存。贴边时只调整左右侧与相对高度。悬停遇见高亮词时立即显示词卡；迟到的查词结果不能盖掉新悬停词。底部词卡按真实高度限制位置，较长的正文在卡片内部滚动。

| 离开采集           | 行为                                                         |
| ------------------ | ------------------------------------------------------------ |
| 词遇切Tab/打开管理 | 跳转前询问，继续留原页；不继续丢弃未加入草稿                 |
| Chrome标签切换     | 无法在原生激活前取消；先释放原页交互，之后询问是否回原页继续 |
| 结束，有草稿       | 可继续、暂不加入并保留、加入后结束                           |
| Chrome原生关闭侧栏 | 不可拦截；释放锁并保留草稿                                   |
| 导航/SPA/文档变化  | 旧位置失效，不误存到新页；草稿保留原来源                     |

范围会话绑定 tab/document/generation；Worker 恢复后，仅允许原文档继续。捕获监听不等于对任意网站脚本的沙箱，复杂编辑器和站点仍须兼容性测试。

## 网页兼容边界

高亮使用CSS Custom Highlight绘制真实Range，不把正文Text节点拆成span，也不重写段落或调整正文盒模型。退出模式、重载或失效时只删除词遇的六个`leximeet-*`注册名和自有UI/样式，保留网站及其他扩展的高亮；浏览器不支持该API时明确提示升级，不用改写正文模拟高亮。

一个词跨`em`/`strong`或换行时，采词描边按每行Range rect合并相邻片段；命中读取该行矩形和`elementFromPoint`的实际顶层元素，检查正文归属，减少点穿导航/弹窗。当前是基本遮挡检查，复杂叠层、变换和编辑器仍须实站验证。实现见[正文和命中](../page/document.ts)、[逐行描边](../page/word-selector.ts)、[高亮生命周期](../page/reader.ts)。

现有自动化检查会确认只读扫描前后的正文 HTML、元素数量和段落矩形相同，也会检查收栏或拖球后正文未被改写；这些检查不等于所有站点均兼容。侧栏收放后的阅读锚点、嵌套滚动容器及用户主动滚动后停止自动校正仍列入[兼容路线](路线图.md)，不把当前窗口夹紧当成完整锚点恢复。

## 学习和练习

今日学习显示来源/完成数；学习规划用两步弹窗“选择目标→设置计划”，最后一次保存。我的词库有状态筛选，日期过滤只在遇见记录；词库支持主词性和资料来源筛选；默认只浏览词条，加号旁的铅笔开启多选，完成图标退出并清除选择。支持分页多选、批量加入多个单词本与确认回收。编辑个人内容前读取当前词条版本，支持网页采集后立即记笔记；打开后的草稿绑定词条和 revision，真正并发修改仍拒绝覆盖并保留输入。

六种方式共用冻结范围，但各自保存当前词、完成进度和草稿。临摹和默写使用等宽加粗字符与当前字母光标；输入错字 300ms 后重写本词，中间的重复练习会短暂显示反馈再继续。本词完成且保存确认后，至少停留 1 秒；发音尚未结束时保留原题，再按自动下一词设置继续。组合输入与粘贴不视为逐字作答。只有范围切换时才询问是否保存，模式切换不会中断。提交失败时保留原题和 ID，需显式重试，不显示虚假成功。[计分规则](学习与复习.md)

选义题提供2–4个真实短义，四宫格在窄屏下纵向排列，错项和正确项同时有非颜色反馈，图标预留空间保持选项高度稳定。正确且保存确认后停留1秒自动下一词，错误留在当前题；切模式、离开、弹窗及重开清除旧计时和在途题目。准备下一题时保留原词头、选项和反馈，整题就绪后一次切换，不把卡片卸载成加载文字；保存禁用只阻止交互，不淡化整张卡片。缺真实释义/语境时允许换方式或跳过，不造题。声音与视觉独立，减少动态效果关闭非必要动画。当前题发音未结束时不自动切题；媒体错误、停止或超时恢复继续，换方式/离开立即取消声音与旧计时。

答题落盘后，可点击练习区域的空白处继续；控件、输入、词表和弹窗不触发换词。“上一个”用于回看，同题不重复计分。进度依据本方式已确认完成的词数，最后一个词完整结算后显示100%，切换方式不会覆盖其他方式的位置。跳过不计完成；调整重复次数不撤销已确认完成题。列表按钮明确显示“熟悉 +1”“不熟悉 −1”。

学习规划用紧凑的目标状态分布、14日实际作答柱形、7日已知复习柱形和每日新学额度比较替换大直线。今日候选与逐日预览置于下方；没有历史时显示空状态，不制造趋势。额度比较只有预览效果，调整计划需要明确保存。

## 设置与词卡

完整词卡呈现阅读字段，不显示原始JSON或内部身份。选择“完整”或“自定义”立即打开字段确认对话框：完整默认全选，调整字段转为自定义；取消保留原预设，确认保存后生效。隐藏阅读语境时，会同时隐藏语境标签和正文；若正在查看语境，则回到释义。重开后仍遵守该设置，恢复字段后可再次读取原语境，事实始终保留。个人内容只编辑笔记和多个单词本；公共释义不可覆盖。网站授权每页显示6项，并支持查找。

合法修改自动保存，页尾也可点击“保存设置”确认。非法或空数值保留草稿并提示未保存，修正后再保存。每次成功重新触发提示动画；减少动态效果时保留新反馈但关闭动画。发音弹窗的标签在组件上方，窄窗单列显示，试听说明独立换行。

## 教学

固定工具栏或暂不固定→真实侧栏→管理页目标/计划→包内文章遇见→词卡→点词采集→加入→收栏→浮球开/关遇见→拖拽采词→右键开栏→再右键收栏。真实成功才推进。普通网页不创建教学框；完成或跳过后，仅从设置明确重新进入。

批注标题支持拖动、键盘移动、收起和跳过；布局会围绕实际目标避让，并在窗口缩小时限制位置。网页、管理页和侧栏只展示当前阶段。可从设置重新进入教学，不会重置个人资料。工具栏属于浏览器 UI，使用图示讲解，不伪造页面按钮。
