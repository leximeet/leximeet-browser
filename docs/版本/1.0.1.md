# LexiMeet Browser 1.0.1

本次更新完善 Chrome 与 Edge 商店发布流程，产品继续支持独立学习和可选 Desktop 阅读采集。实际商店版本以公开详情页为准。

## 本版变化

- 正式版本标签触发双商店自动上传、提交正常审核；通过审核后按商店设置上架。
- 上传前要求完整独立 UI、固定 Desktop/Core 真实连接以及同源码、同生产内容门禁通过。
- 发布使用验收后的原样 ZIP，源码、SHA-256 和真实连接来源随 GitHub Release 附件保存。
- Chrome 使用服务账号与 Web Store API V2；Edge 使用新版 Client ID/API Key。失败或未知结果停止，避免重复写请求。
- 完善商店配置、失败补发和当前 Desktop 安装器的审核说明；修复词卡重载测试提前读取异步资料的问题。

LMCP 合同仍为 1.0.0，Dictionary 仍为 0.0.3，个人资料格式没有变化。更新应保留已有词库、笔记、单词本及学习记录。

## 安装与发行文件

- [Chrome 商店](https://chromewebstore.google.com/detail/%E8%AF%8D%E9%81%87-leximeet/ffpencpinagmaiggednonfipgfmgmcdn)
- [Edge 商店](https://microsoftedge.microsoft.com/addons/detail/%E8%AF%8D%E9%81%87leximeet/lokiongmifeccfecjjcmcdpihpohfmnc)
- [GitHub Release](https://github.com/leximeet/leximeet-browser/releases/tag/1.0.1)：两份浏览器 ZIP、完整对应源码、LICENSE、SOURCE.json、独立及连接安装包清单、SHA256SUMS。

源码连接测试使用隔离 Chromium 与固定 Desktop/Core 组合，不能据此宣称其他操作系统或正式 Edge 已逐一验收。CI 的“提交审核成功”也不是商店已上架。
