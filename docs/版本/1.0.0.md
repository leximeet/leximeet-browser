# LexiMeet Browser 1.0.0

词遇的首个正式浏览器插件版本。可以独立学习，也可以连接 Desktop，在网页遇见单词并保存真实语境。

## 主要功能

- 网页即时词卡、正文高亮、原生侧栏与悬浮球拖词采集。
- 独立词库、笔记、多单词本、筛选、批量整理和回收恢复。
- 学习规划、六种练习、0–30 熟悉度与独立 FSRS 排程；各模式进度独立，正确反馈显示一秒后继续。
- 默认单句脱敏和七天重复语境检查；同词同句忽略大小写，不把不同句子合并。
- 双端自动发现、真实浏览器确认连接和显式断开；连接时封存独立资料，网页读写使用桌面，临时失联不自动切回独立库。
- Dictionary 0.0.3 Lite Text 内置，Core Text 可按需安装。

## 安装

日常使用从商店安装：

- [Chrome 插件](https://chromewebstore.google.com/detail/%E8%AF%8D%E9%81%87-leximeet/ffpencpinagmaiggednonfipgfmgmcdn)。扩展 ID：`ffpencpinagmaiggednonfipgfmgmcdn`。
- [Edge 插件](https://microsoftedge.microsoft.com/addons/detail/%E8%AF%8D%E9%81%87leximeet/lokiongmifeccfecjjcmcdpihpohfmnc)。商店列表 ID：`lokiongmifeccfecjjcmcdpihpohfmnc`。

Edge 商店列表 ID 是加载项页面地址中的公开标识。Partner Center 的 Product ID 是另一组 GUID，只用于维护者上传，不出现在安装入口。

## 安装包

核对发行物或使用开发者模式时，从 [GitHub Release](https://github.com/leximeet/leximeet-browser/releases/tag/1.0.0) 下载 `leximeet-browser-1.0.0-chrome.zip` 或 `leximeet-browser-1.0.0-edge.zip`。

1. 下载匹配浏览器的 ZIP 并解压到固定位置。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展”，指向包含根 `manifest.json` 的解压目录。
4. 按[用户指南](https://github.com/leximeet/leximeet-browser/blob/1.0.0/docs/用户指南.md)完成首次教学；连接 Desktop 时按[桌面连接](https://github.com/leximeet/leximeet-browser/blob/1.0.0/docs/桌面连接.md)注册本机 Host 并确认邀请。

要求 Chromium 142+。两份安装包的生产文件经逐字节等价检查；完整自动化使用隔离 Chromium，不替代正式浏览器上的系统通知、Native 授权和其他操作系统验收。商店安装使用上一节的公开标识。

## 本版修复

词典安装清单使用 `dictionary-manifest.json`，不再产生第二份扩展 `manifest.json`；随包词典展开为普通 JSON/JSONL，避免 Edge 拒绝内嵌压缩文件。上游词条与来源校验保持，Core 增量下载格式不变。

## 对应源码与验证

附件另含完整 `leximeet-browser-source-1.0.0.tar.gz`、`LICENSE`、`SOURCE.json`、`store-packages.json` 与 `SHA256SUMS`。下载后执行 `shasum -a 256 -c SHA256SUMS`。

标签 CI 对原样 Chrome 生产文件运行完整独立 UI，再核对两份 ZIP 与生产文件；发布任务复用通过检查的 ZIP，附同一提交的完整源码。`SOURCE.json` 记录本轮独立检查及生产摘要；真实 Desktop 连接由独立工作流验证，结果应结合其精确 Browser/Desktop/Core 来源读取，不累加旧候选计数。

本版不迁移未发布的 0.x/rc 测试库，没有账号或云同步。正式用户资料从 1.0.0 开始维护升级承诺。
