# LexiMeet Browser 1.0.2

本版修复网页采集离开时的误确认及不会关闭的提示。独立学习与可选 Desktop 连接的范围保持不变。

## 本版变化

- 没有待加入草稿时，切网页、切换遇见/采集或打开管理页直接结束采集，不再弹保存确认；移除最后一条草稿后同样可直接离开。
- 有草稿时仍需决定，草稿绑定原网页、文档和归属；已加入单词本的内容保留。
- 网页导航、采集回执及错误提示在 3.5 秒后关闭。连续出现相同提示会重新计时，旧计时不能提前关闭新提示。
- 修复 Edge 发布状态查询的 HTTP 202 处理，支持沿已受理操作恢复送审，避免重复上传。

LMCP 仍为 1.0.0，Dictionary 仍为 0.0.3，个人资料格式没有变化。更新保留已有词库、笔记、单词本及学习记录。
