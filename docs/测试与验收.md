# 测试与验收

自动化默认全部无界面，不操作系统键鼠、剪贴板或系统日期。每例独占 Chromium、profile 和回环端口；真实连接另外独占 Desktop、Core 和 Native 注册，只清理自己拥有的资源。只有人工 lab 才显示窗口。

## 分层命令

| 命令                                                                      | 范围                                               |
| ------------------------------------------------------------------------- | -------------------------------------------------- |
| `npm run format:check`                                                    | 格式门禁，不改变冻结合同/向量                      |
| `npm run typecheck`                                                       | Vue/TypeScript                                     |
| `npm run verify:connector`                                                | 17份规范、20份冻结文件及完整合同摘要               |
| `npm test`                                                                | 纯规则、共享向量、IndexedDB事务、连接/生命周期模型 |
| `npm run build && npm run verify:manifest`                                | Chrome 正式MV3、七项权限与资产                     |
| `npm run build:edge && npm run verify:manifest:edge`                      | Edge 正式MV3、七项权限与资产                       |
| `npm run zip && npm run zip:edge && npm run verify:store-packages`        | 两端 ZIP、内层压缩拒绝、字节等价及来源             |
| `npm run test:browser`                                                    | 原样生产扩展、真实原生SIDE_PANEL、独立UI/重启      |
| `npm run verify`                                                          | 静态、单元、Chrome构建及完整独立UI                 |
| `npm run test:connected`                                                  | 实际Native→Main→Core，双端九场                     |
| `LEXIMEET_UPGRADE_FROM=/path/to/previous/chrome-mv3 npm run test:upgrade` | 同profile实际包替换及稳定事实                      |

原生侧栏必须断言 SIDE_PANEL，不能用普通标签或源码组件注入替代。所有真实扩展测试都逐文件核验生产字节，不修改 manifest、替换权限 API、修改日常 profile 或伪造同意。测试零重试、零跳过，禁止 only；失败时保留报告并说明原因，不能汇总历史计数冒充完整通过。

Chrome 自身设置页的语言可能跟随操作系统，不能用网页的 `locale` 推断 WebUI 文案。图钉教学通过固定 Chromium 版本的原生开关操作，并读取 `chrome.action.getUserSettings()` 确认实际状态。侧栏关闭后先等待原生文档销毁及浮球的“打开侧栏”投影，再验证键盘重开，避免把两步异步更新当作已同时完成。

业务Clock注入在学习仓库，不改操作系统时间。单测覆盖六方式、状态/FSRS/衰减、额度、提醒队列口径、笔记、目标更换、查重与重开；独立Browser不实现系统学习提醒。真实浏览器覆盖Markdown、默认隐私、重复采集、设置重启、快点击和练习重开。提示及下一词的可操作状态须跟随实际事务：保存中禁用，回执确认后解锁；音频用真实HTMLMediaElement的playing事件确认，失败重试保留完整输入与计分断言。事务回归另外用真实答题推进到FSRS到期生成初学资格，验证提前主动完成、同日按词去重、FSRS不延长、自动队列仍等待到期，以及撤销后的事实保留；不注入虚构记忆状态。

候选替换的前包也必须使用当前 `leximeet-browser-personal/4` 格式。测试先读取前包的真实资料格式，格式不符立即报错；不能通过把旧profile清空来制造“升级通过”。未知/旧格式拒绝用单元与真实扩展拒绝测试单独验证。

升级时必须先退出旧进程，再替换实际生产包，最后从同一 profile 启动新进程。两份 manifest 的版本相同时，只称“同格式候选替换”；软件版本不同时，才称版本升级。无需维护 0.x/rc 测试库转换。[兼容政策](版本与兼容.md)

练习视觉稳定回归读取实际冻结题 ID，点击真实选项，使用 MutationObserver 和逐帧采样检查保存及完整切题：四项始终存在，选项 x/y/宽/高不变，禁用时 opacity 仍为1，换词不早于真实积分回执后一秒。另以真正 IndexedDB 写事务 abort 验证原题和零成绩保留，显式原 ID 重试后才计时；不替换服务回执或生成测试成绩。离开、换方式、弹窗和重开分别验证旧计时取消，错误超过一秒仍留原题。连续真实 IndexedDB 读请求延迟写事务完成，在保存中离开并返回后释放事务，检查只保存一条原题成绩、仍留原词且手动下一词可用；不伪造事务回执。另用1.5秒真实WAV验证发音 ended 先于自动切词，以及实际503媒体失败仍能继续；播放器单元覆盖开始播放后仍未结束的超时释放。原生侧栏关闭等待Chrome实际文档结束，不扩大忽略权限错误的范围。静态前后图片仅展示界面，计时和原子性依靠上述行为证据。

## 设置、词库和学习体验回归

- 教学：真实跳过后重开，普通网页不创建教学框；连接及断开后也验证。
- 控制恢复：Desktop 断开关闭端口、一次探测失败后仍查证原配对；临时失联不能解封 A，独立且未发现桌面时不执行快速宿主探测。
- 设置：完整/自定义自动打开字段确认、完整默认全选且调整转自定义、取消不改正式设置、真实采集语境隐藏/重开/恢复且事实不变、完整词卡无原始JSON、网站列表分页/查找、非法输入、再次保存反馈；明暗及390px窄窗。
- 词库：公开目标回收后重开不重生、恢复原ID、跨页51词原子操作、笔记与多本关联、词性和来源筛选。冲突、容量与连接封存按事务拒绝。
- 六方式：分别保存游标、部分输入和完成数；真实退出重开恢复；末词完整结算100%，上一个及空白继续不重复计分。
- 规划：目标状态、14日实际作答、7日已知复习、每日额度比较、逐日候选、暂停和时区日历；重复/揭晓/撤销/未来事件口径明确，预览不改计划或产生学习成绩，不伪造未来复习量。
- 完成进度：十题混合结果、最后题答错后10/10；切方式、保存与整浏览器重开保持；跳到末词不伪造满格，结束后补练缺词不重复计分；完成回执不随展示草稿倒退。
- 词库编辑：默认无勾选框、加号旁进入/退出编辑，退出清空选择；跨页保留、筛选清除，重开恢复浏览状态。

## 连接九场的主要边界

连接九场覆盖自动发现、两端发起、真实确认窗和取消，以及 A 的封存与恢复（包括真实笔记及多本关联）。侧栏、浮球和词卡三个入口的 Desktop 写入，以及大小写、emoji 和 WordRef 都在验证范围内；ACK 不确定时仍沿用原 ID。测试也覆盖临时失联、停机重开、恢复和撤权，并检查重复的安全语境不增加事实、关系或通知。测试还覆盖实际 CLI SIGINT、启动教学和自有注册清理。原生阅读列表按词归并并保留原位置，同句两处不重复写入 Desktop，不同句保留两条。连接期间，独立 A 保持封存。

阅读业务的教学前置只点击教学页或管理页中的一个真实“跳过”入口，再等待教学状态和管理页同步收敛。两个表面订阅同一进度，不能按瞬时按钮数量先后重复点击；全套仍保留连接、笔记、多本关联与原生侧栏断言，不用延长超时或增加重试掩盖前置竞态。

应用包链与源码链分别验收；源码通过不能证明随包 JRE/Host 也通过。验收环境严格固定消费来源、构建摘要及Desktop/Core组合；产品正式连接则按major、最低服务版本和必需能力/方法协商，区别见[兼容规则](版本与兼容.md)。单元另覆盖正式不同摘要和较高服务版本、缺必需能力/方法、最低版本、预发布严格身份及响应版本绑定；这些未来版本消息样例不冒充真实未来服务联调。云同步、反向能力和账号没有由本地链证明。

## 本地验收与CI

每次发行按[验收门禁](验收基线.md)重新核验固定生产包。实际通过数、源码与桌面安装物组合、未执行项随对应发行物记录；改变后的包不能沿用历史计数。源码连接、随包 Native/JRE 连接及安装是不同验证层，分别说明，不拼接局部结果。

`ci.yml` 对 main、无 `v` 前缀的版本标签（首版 `1.0.0`）及 PR 检查格式、类型、单元、两端 ZIP 与完整独立 UI。先打包、再对同一生产字节验收；ZIP 和目录逐文件一致、没有内层压缩档案、Chrome 与 Edge 逐文件相同后才输出 `browser-store-packages` artifact。随包词典使用普通 JSON/JSONL，测试覆盖展开文本与上游内容一致、资产摘要、查词及 Core 增量安装。分片编码或解析代码变化后重新跑完整独立 UI 与真实连接；旧候选的通过数不能作为新包证据。正式 Edge 实测仍单独记录。

真实跨仓连接与旧候选替换保留手工工作流，输入实际来源 ref；Core 提交必须等于 Desktop 的固定 gitlink。三个验证工作流仅 `contents:read`，不用 `pull_request_target` 或商店密钥。`edge-draft.yml` 另有 `actions:read` 以读取成功报告，仅允许从 main 手动触发、核验同一源码的独立与真实连接 CI，在最终步骤读取 Edge 密钥并上传草稿；不提交审核或发布。[配置与步骤](发布指南.md#6-github-actions-上传-edge-草稿)

**工作流配置和上传脚本单测不代表远端 Actions 或商店上传已经成功。**

报告在`test-results/`、`playwright-report/`，可用`LEXIMEET_TEST_OUTPUT=/path/to/owned-output`转存。HTML不自动打开，失败保留截图/trace。调试可显式`npm run test:browser:visible -- tests/browser/onboarding.spec.ts`；正式自动联调禁止headed/debug。

## 人工及平台边界

系统通知横幅/专注模式/安装警告、原生图钉、实际音质和真人输入法、正式Chrome/Edge及Windows/Linux须单独记录。当前macOS无头结果不能外推其他宿主；也不证明签名安装、商店审核、远端发布或云数据一致性。

网页兼容人工验收补充：保留站点/其他扩展的高亮；跨内联节点、换行和覆盖元素不误选；侧栏开合保持窗口/嵌套容器的阅读锚点，用户滚动后不继续抢回位置。锚点和复杂遮挡属于待补平台场景。选义另外抽审多义、同形词和相近干扰项，自动去重和答案ID唯一不等于自然语言只有一个合理答案。
