# 学习与复习

这是 Browser **独立模式**的规则。连接后只读取 Desktop 的学习状态，不在浏览器运行第二套练习和排程；系统学习提醒由 Desktop 实现。

规则版本 `leximeet.learning/2`；FSRS `fsrs-6/java-fsrs-1.0.0`，配置 `leximeet.fsrs6/1`。**熟悉度负责状态，FSRS负责到期安排**，两者共同限制今日复习队列。

## 学习规划

一份资料只有一个当前目标和一份当前计划。先选择词书或当前整本词典，再设置配额，最后统一提交；只选择目标时不会提前生效。默认新学 **10**、复习 **20**；新学数量需为 1–50 的整数，复习数量需为 0–500 的整数。提交和持久化读取时都校验同一输入范围，不保留预发布旧计划的大额度例外。

调整计划时保留 ID、目标、开始日和时区；更换目标时建立新计划，保留单词、学习事件与私人语境。暂停计划只停止引入新的目标词，已开始的词、已确认的遇见和到期复习仍可继续。弹窗保留打开时的修订号；若另一窗口先保存，旧提交会被拒绝，界面显示冲突并保留编辑稿。

## 状态与熟悉度

初始分数为 **10**，最低 **0**、最高 **30**。状态取决于学习经历和休息周期，不能仅按分数划固定区间。

| 状态   | 当前含义                                                             |
| ------ | -------------------------------------------------------------------- |
| 未学习 | 尚无新规则下的有效反馈；加入今日队列时可展示“待学习”，不持久化伪事件 |
| 学习中 | 已开始但从未达到 20 分；包含答错后低于 10 分的词                     |
| 待复习 | 曾达到 20 分，当前不在休息周期；即使后来降到 0 分仍属于待复习        |
| 已熟悉 | 从低于 30 实际达到 30 分，进入休息；自然衰减到 29–21 时仍保留该状态  |
| 不熟悉 | 0 分的独立筛选，可与“学习中/待复习”重叠，不替代主状态                |

首次达到 20 分完成初学，保存首次时间和学习日；最早从该时区的下一自然日零点开始复习。后来降分不会撤销已经完成的初学，撤销对应学习事件则按剩余事件重新投影。

实际跨越到 30 分才启动一个休息周期：72 小时保护期后，每满 48 小时减 1 分，即第 5 天 29、第 7 天 28、第 23 天 20。自然衰减只到 20，不继续扣至 0；到 20 时释放休息保护并加入可复习状态。期间错答可提前打破保护。离线重开直接按时间重算，不补写虚假的衰减答题或 FSRS 事件。

## 六种练习与第一次反馈

| 首次反馈                                 | 积分 | FSRS                                      |
| ---------------------------------------- | ---- | ----------------------------------------- |
| 列表“熟悉”、选义正确、临摹完成、听音正确 | +1   | 临摹不更新；其余独立回忆按到期条件写 Good |
| 默写、语境填空独立正确                   | +2   | 按到期条件写 Good                         |
| 错答、列表“不熟悉”                       | −1   | 独立失败写 Again；临摹不更新              |
| 查看答案、显示提示                       | −1   | 不更新                                    |
| 已辅助后完成                             | 0    | 不更新                                    |
| 同一题后的订正/再次完成                  | 0    | 不更新                                    |

当前题目身份来自范围会话、词身份和模式，位置由冻结队列绑定；跨端事件身份改造见[路线图](路线图.md)。切换模式时仍使用同一范围，但题目属于不同练法；切回原题不会重复获得首次计分。错误后订正、按重复次数设置作答和 Enter 连按不会重复推进积分或 FSRS。六种方式均在练习范围右侧提供“重新开始”，可随时生成新会话并保存新断点。重练从第一个词开始，保留当前方式，重新建立各词草稿及本轮答题锁，不清空已记录的分数和事件。练习次数不限；即使练习 100 次，单词分数仍限制在 0–30，没有每日得分或使用次数上限。

临摹/默写输入在自己的聚焦框处理；听音/填空整词输入由 Enter 确认。重复次数 **1–10**。完成最后一遍才触发临摹/默写的词音；看词选义默认不读词；听音的音频是题目本身。反馈音效可关闭。选义正确并保存确认后停留1秒自动下一词，错误不自动跳过；完成本词拼写后也停留1秒，拼写设置可关闭自动推进。打开弹窗、离开、换方式或重新开始清除旧计时，未知回执不允许定时换词。

题目由可信学习服务先生成并冻结：实际词 ID、词头、大小写规则、选义选项和正确项、真实语境。提交只携带答案/选项/反馈及提交 ID，不能从 UI 注入“正确”、分数或 FSRS 状态。词典不足两项真实短义时，不生成选项；没有包含本词的真实句子时，不生成填空题。

选义目前排除完全相同短义和已知重叠释义，优先选择相同词性的真实干扰项；这只是字符串与词性筛查。多义、同形词及近义选项仍需人工抽审，不能据此宣称每题语义无歧义。正式发行前及词包更新后按[题目质量路线](路线图.md)抽样复核。

## 学习事件、排程与今日额度

`PracticeAttempt.learning` 保存稳定提交/题目 ID、词身份、设备序号与逻辑顺序、方式、反馈、辅助标记、时间/学习日/时区和规则版本。有效独立回忆另写带来源提交 ID 的 `ReviewFact`。词条物化、学习事件、FSRS 记录和顺序号在同一事务中提交；重复提交相同 ID 和内容时返回原回执，同一 ID 换成不同内容时则拒绝。

提前独立答对可加熟悉度，但已有尚未到期的 FSRS 不延后；独立失败即使提前发生也进入 Again。临摹、提示和辅助完成不伪装成独立回忆。仅临摹达到 20 分时使用首次回忆兜底时间，不凭空制造 stability/difficulty。

自动复习候选时间取 FSRS 到期（或首次回忆兜底）与学习/休息释放时间的较晚者；不能在未毕业或休息中仅因 FSRS 到期就入今日复习。主动自由练习的完成量另按已生效的复习资格计算，不要求FSRS已到期。

| 今日指标       | 计数方式                                                                 |
| -------------- | ------------------------------------------------------------------------ |
| 初学完成       | 当天第一次达到 20 分的不同词；换目标、回收或重启不补额度                 |
| 复习完成       | 已具复习资格的首次无辅助独立答对，按不同词去重；同日初学、休息中的词不计 |
| 失败/提示/临摹 | 不消耗复习完成额度；订正不补记独立成功                                   |
| 答题次数       | 可包含订正等真实操作，不能直接当学习完成数                               |

例如：某词已完成初学，复习资格从今天生效，但FSRS建议三天后再提醒。今天主动练对计一次复习完成，同词再练仍计一次；它不会提前进入自动队列，也不会因为提前答对把FSRS期限延后。临摹、提示和同题订正不算独立完成。

所有已经确认但未毕业的遇见优先进入队列，最多 200；继续学习的词最多 200，即使已经离开当前目标也会保留。计划只补充剩余的新词名额。到期复习按时间排序，并扣除今日完成数；当天已完成又答错的词可以继续巩固，不重复扣除额度。自由练习的范围不受今日任务数量限制。

今日断点绑定学习日和目标身份，跨日或更换目标重新建立，调整每日额度可继续同日范围。切词、切模式和保存后，各词在不同模式下的草稿都可恢复；重复第 6–10 遍时也遵守设置上限。保存范围进度时，只保存队列、游标、模式草稿和展示设置，不再次提交已经记录的答题；只有换范围时才询问是否保存。正在落盘或失败待重试时，禁用提示、下一词、换方式和保存断点；失败后保留原提交 ID。后台依据同一事件投影为网页匹配提供状态，内容脚本不接收全量个人学习事件。

## 本轮进度与规划面板

练习进度是当前方式中已确认完成的词数，按词去重；已保存的完成回执不因输入草稿变化倒退。它与单词积分、首次完成初学和当天初学额度分别统计。答错的选义题已完成作答；拼写仍需完成设定重复。仅查看答案、跳过缺题和未确认的写入不增加进度。切方式各自保留，跳过词可补练。

规划页的14日作答使用真实未撤销反馈，按规划时区归日，不计揭晓和未来事件；同词同日去重，重复次数仍可查看。7日复习使用活动词当前真实到期日期，逾期归今天；不根据新学额度编造未来复习。额度方案仅是只读初学量与日期比较，不改变计划、分数或FSRS。

## 持久化与撤销

正式应用 1.0.0 之前，不迁移 0.x/rc 测试库，不换算旧分数，不保留旧手动掌握或旧 FSRS 解释器，也不提供旧资料导入。测试时直接建立当前模型的隔离空库或使用固定种子。正式 1.0.0 及以后产生的真实资料必须跨版本保留。

个人资料导入导出、旧候选转换和旧学习确认流程已移除。新库直接建立当前模型；旧库或未知格式拒绝并保留，不自动清空用户库。当前模型内的多表事务、重启、回收恢复、损坏拒绝、Core公共资源升级和连接前内部封存仍保留。

`LearningRepository.undo` 只允许撤销当前词的最后一个学习事件，同时撤销关联 FSRS；重放后恢复积分、初学、休息和排程。它是事实仓库能力，当前没有另加批量撤销或历史编辑 UI。

## FSRS实现与固定配置

运行时由三层组成：参数、纯数学估计、步长排程。数学层按[FSRS官方公开公式](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)独立实现稳定性 S、难度 D 和回忆概率 R；不包含 Java 调度器的移植程序。排程层使用固定初学步长1/10分钟、再学10分钟；初学首步 Hard 为5.5分钟，再学 Hard 为15分钟。目标回忆率90%，长期间隔按 S 四舍五入为1至36,500天，不启用随机扰动。

`fsrs-6/java-fsrs-1.0.0` 是跨端冻结规范和参考向量的标识，当前 Browser 不运行 Java 或依赖 Java SDK。`leximeet.fsrs6/1` 保留固定21个参数、完整经过天数、JavaScript浮点精度及同日 Good/Easy 的稳定性保护。它不是上游最新默认参数；不能直接升级另一种 SDK 默认策略而继续声称相同配置。FSRS排程的经过天数以完整24小时计算；学习资格与今日额度另按规划时区的自然日计算。

数学或排程变更须同时核对跨端36次黄金排程、真实事件顺序、撤销重放和事务。生产事件仍记录算法标识，未知标识明确拒绝；不能从显示分数重建记忆估计。

## 练习进度和规划预测

同一冻结范围内，六种方式分别保存游标、输入、逐词反馈和已完成数量。只有保存回执确认后的完成才计入进度；完成最后一个词后为 100%。使用“上一个”或重新切回原题时，保留首次反馈锁；“重新开始”会创建新的练习会话，次数不限，分数仍限制在 0–30。回收词会退出活动队列与断点，学习事实不会删除。

规划曲线只推演初学额度覆盖：当前已初学目标词 + 预计完成的新词额度，最多到活动目标总数。每日预览按当前顺序分配候选，优先继续已开始的词；不是未来固定课表。完成日期取规划时区的自然日，不按固定24小时跨夏令时相加。暂停、漏学和重复巩固会改变实际日期；不模拟未来FSRS、得分或熟练率。
